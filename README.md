# MCI Group

Marine Corporation of India (MCI) is a sovereign maritime infrastructure and engineering website covering deepwater operations, fleet logistics, marine repairs, dredging, energy support, and maritime technology.

## Local development

```bash
npm install
npm run dev
```

The Vite development server will print the local URL in the terminal.

## Production build

```bash
npm run build
npm run preview
```

## Project structure

- `src/` — application pages, components, data, and styles
- `public/assets/` — static imagery and media used by the site
- `index.html` — application entry document

## Technology

- Vanilla JavaScript modules
- Vite
- CSS with responsive layouts and shared visual tokens
